后续三道失败来自过度拒答或追问附加条件：现在允许说明政策的明确适用条件，而不假定用户身份；试用期只能说明期限及评估，不能承诺转正；追问只补全主题。人工抽查这三道输出符合上述要求，其余结果仍应结合原始记录核对。

检索检查：关键词在 14 道有答案题中有 13 道的全部指定证据进入前三；语义检索为 14/14。当前政策文档较短，块数少，这个结果不能证明长文档检索效果。追问检索指标使用数据集预设独立问题；回答链路则实际运行模型改写，二者不同。
